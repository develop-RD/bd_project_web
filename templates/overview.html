Обзор сервиса

Краткое описание функционала с обучающими видеороликами. Выберите нужный раздел и посмотрите, как это работает.

Работа с недельными отчётами

Каждый сотрудник заполняет свой отчёт по дням недели: выбирает проект, указывает наименование задачи, потраченное время и результат работы. Руководитель лаборатории видит отчёты всех сотрудников и может при необходимости скорректировать записи.

Работа с планами-графиками

Планы-графики позволяют ставить задачи на сотрудников, задавать сроки, длительность, прогресс и зависимости между задачами. Доступны иерархия подзадач, ответственные из разных отделов, экспорт в DOCX и просмотр результатов, пришедших из недельных отчётов.

Подгруппы

Внутри проекта задачи можно объединять в подгруппы — например, «Корпуса», «ПО», «Документация». Подгруппы сворачиваются, переставляются местами, а задачи внутри можно сортировать по датам или приоритету и перетаскивать вручную. Так же доступен механизм движения задач, связывания задач,добавления родительских задач,добавления подзадач.

Статистика

Начальникам лабораторий и начальникам отделов доступна возможность просмотра статистики. Можно устанавливать период по времени для анализа статистики по проектам каждого пользователя.
